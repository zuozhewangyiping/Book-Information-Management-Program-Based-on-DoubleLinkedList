项目一 基于线性表的图书信息管理 —— 功能测试样例
====================================================

运行方式
--------
    按菜单提示先输入功能编号，再按下面各功能的“输入”逐行输入。
    一次运行可以连续测试多个功能，最后输入 0 退出。

几点说明
--------
1. 菜单文字、“请选择：”、“请输入书单，以 0 0 0 结束：”等提示语是程序交互
   界面的一部分，不算在下面的“期望输出”里；期望输出只列该功能自身应打印的结果。
2. 书单以单独一行 “0 0 0” 结束（三个 0 用空格分隔）。
3. 每本图书一行：书号 书名 价格，用空格分隔；书名内部可以含空格和括号，
   解析时以第一个字段为书号、最后一个字段为价格，中间全部算书名。
4. 价格统一以两位小数输出。
5. 下面各功能的输入数据互相独立，每次测试都从“选择功能编号”开始。

附：边界与异常情况（可选，用于验证健壮性）
------------------------------------------------------------
a) 空表：输入功能 1（或 2、3、6、7、8）后直接输入 “0 0 0”
   —— 代表输入了空表（等同于未录入书籍），一切正常。
b) 删除全部：功能 5 输入位置 1，反复 n 次，最后表为空。
c) 排序/逆序后再输出：可连续操作，验证链表头尾指针仍正确
   （例如先 8 逆序，再 1 创建输出）。
d) 非法选择：输入 9 等不存在的编号，应提示“无效选项”并重新显示菜单。
e) 输入放行：在用户输入格式合法的情况下，不会对用户具体的输入内容进
   行合理性校验（如价格的合理性）。
f) 数据丢弃：用户输入的书籍信息行中只要检测到 EOF 就整行作废，该行
   已输入内容全部作废，且直接中止输入（等价于"0 0 0"）。
